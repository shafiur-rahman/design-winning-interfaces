# Creative direction

Use this to create a defensible visual system rather than a collage of fashionable effects.

## Form the visual thesis

Use the formula:

“Because [audience tension], express [brand truth] through [formal principle], so the experience feels [emotional outcome].”

Name the direction with a concrete phrase such as “Measured Momentum” or “Human Precision.” The name is a mnemonic, not marketing copy.

Define one signature device. It may be a data behavior, editorial rhythm, spatial motif, material treatment, illustration logic, or transition. It must arise from the product story and remain usable across several sections or states.

## Specify the system

### Typography

- Choose type for voice, character coverage, legibility, loading cost, and licensing.
- Limit the core interface to one family or a deliberate two-family pairing.
- Define roles for display, heading, body, label, data, and code.
- Set an intentional type scale, line length, line height, weight range, and number treatment.
- Avoid a fashionable font pairing that could be swapped into any startup unchanged.

### Color

- Start with semantic roles: canvas, surface, text, muted text, border, action, focus, success, warning, and danger.
- Add expressive color only after the functional palette works.
- Test contrast in actual component states, not palette swatches alone.
- Never rely on color as the only status signal.

### Composition

- Define container width, columns, gutters, alignment anchors, density, and vertical rhythm.
- Use contrast in scale and space to make focal order obvious in grayscale.
- Introduce asymmetry only when it strengthens sequence or identity.
- Keep a recognizable silhouette at both desktop and mobile widths.

### Shape and depth

- Define a small radius family and border logic.
- Use elevation only to communicate layering, interaction, or hierarchy.
- Avoid mixing glass, heavy shadow, outline, and flat styles without a system-level reason.

### Iconography and imagery

- Use one icon family with consistent stroke, size, optical weight, and fill behavior.
- Give photography, illustration, 3D, diagrams, or generated media a precise subject, framing, lighting, texture, and color direction.
- Avoid generic “person at laptop,” abstract AI brain, handshake, rocket, and stock-office imagery unless the product truth requires it.

### Motion

- Assign motion a job: orient, explain causality, preserve continuity, signal status, or reward completion.
- Keep common UI feedback quick and restrained.
- Respect reduced-motion preferences and avoid making critical information depend on animation.

## Originality tests

Run these tests before implementation:

- Swap-brand test: if another company name fits without changes, make the direction more specific.
- Decoration test: remove effects; the hierarchy and idea must still work.
- Silhouette test: major regions should remain recognizable when blurred.
- Grayscale test: focal order must survive without color.
- Five-second test: audience, offer, and next action should be inferable quickly.
- Recurrence test: the signature device must work in more than one isolated hero moment.

## Anti-goals

Write three to five explicit anti-goals, such as:

- not sci-fi;
- not luxury through emptiness alone;
- not playful at the expense of operational trust;
- not a dark dashboard made from identical cards;
- not motion-heavy.

Use anti-goals during visual QA to prevent drift.
